# Wireframes

These low-fidelity layouts describe the page structure at desktop and mobile sizes. The project cards currently use CSS artwork so the site does not depend on external image assets.

## Home — desktop

```text
+------------------------------------------------------------------+
| Your Name       [Dark mode]   Home About Services ...             |
+------------------------------------------------------------------+
| Intro, headline, summary, actions       | Profile card             |
+------------------------------------------------------------------+
| What I do:     [Service card] [Service card] [Service card]        |
+------------------------------------------------------------------+
| Selected projects   [Project] [Project] [Project]                 |
+------------------------------------------------------------------+
| Call to action                                  [Get in touch]    |
+------------------------------------------------------------------+
| Copyright                                               Email     |
+------------------------------------------------------------------+
```

## Home — mobile

```text
+------------------------------+
| Your Name      [Dark] [Menu] |
+------------------------------+
| Intro and headline           |
| Summary and actions          |
| Profile card                 |
+------------------------------+
| Service card                 |
| Service card                 |
| Service card                 |
+------------------------------+
| Project card                 |
| Project card                 |
| Project card                 |
+------------------------------+
| Call to action               |
| Footer                       |
+------------------------------+
```

## Interior pages

```text
Shared header
Page title and short introduction
Page-specific content
Contact call to action or form (where relevant)
Shared footer
```

The mobile navigation opens below the header; content grids stack vertically on narrow screens.
